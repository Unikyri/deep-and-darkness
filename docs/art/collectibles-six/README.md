# Deep and Darkness - Six collectible objects

Six static, transparent 1024x1024 PNG icons generated through FAL:

1. Moon Pearl Relic - existing user-approved visual direction.
2. Tide Lantern.
3. Abyssal Key.
4. Bottled Message.
5. Nautilus Compass.
6. Tidebound Grimoire.

The five new icons use the exact Moon Pearl output as their style anchor. Each has its own FAL prop entity in `04 Collectibles - Six Objects`; the originals and masks are retained separately. The new designs await the user's visual assessment. Only the first design's art direction has been explicitly approved.

`collection-preview.png` shows all six together and at 48px/64px. `qa.json` records decoder evidence from the actual PNGs. All six contain real alpha and complete silhouettes. A fine pale rim may remain visible on dark backgrounds, consistent with the first concept; engine-scale rendering is not yet verified.

The ZIP contains six individual PNGs and a manifest whose paths match the archive. Runtime import settings, animation, prefab assignments and gameplay collection order are not part of this generation pass.
